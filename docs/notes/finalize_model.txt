# 9. What is `route_avg_lookup.json`?

This is for **new trips**.

Remember your Gold feature:

```text
route_avg_occupancy_loo
```

During training, you used:

> Average occupancy of OTHER trips on the same route.

Example:

```text
Mumbai → Pune

Trip 1 = 80%
Trip 2 = 75%
Trip 3 = 85%
Trip 4 = 70%
```

For Trip 1:

```text
route average = (75 + 85 + 70) / 3
              = 76.67%
```

You excluded Trip 1's own answer.

That's **leave-one-out**.

---

## But what about a NEW trip?

Suppose the user enters:

```text
Mumbai → Pune
```

There is no final occupancy for this new trip yet.

So there is nothing to exclude.

Therefore we can simply use:

```text
historical Mumbai → Pune average
```

For example:

```text
Mumbai → Pune = 77.5%
```

That's why the code creates:

```python
route_avg = trips.groupby("route")["final_occupancy_pct"].mean()
```

and saves it.

---

# 10. Why `global_mean`?

What if the user enters a route that your historical data doesn't contain?

For example:

```text
Nanded → Goa
```

and your dataset has never seen this route.

You don't have:

```text
Nanded → Goa historical average
```

So you use:

```text
global_mean
```

For example:

```text
global_mean = 64.3%
```

Therefore:

```text
Known route
    ↓
Use route historical average

Unknown route
    ↓
Use global average
```
