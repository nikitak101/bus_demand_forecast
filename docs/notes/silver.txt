# What does "don't trust upstream math" mean?

Your Bronze data already contains:

```text
occupancy_pct = 62.5
```

But Silver **doesn't blindly trust it**.

It independently calculates:

```text
seats_booked = 25
capacity = 40

25 / 40 × 100 = 62.5%
```

Then compares:

```text
Bronze value       = 62.5%
Recalculated value = 62.5%
```

✅ Correct.

Suppose Bronze accidentally said:

```text
Bronze occupancy = 72%
```

but:

```text
25 / 40 × 100 = 62.5%
```

Then your validation catches the mismatch.
